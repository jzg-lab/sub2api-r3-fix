本轮重点核对现有决策、老板 r17bg 后的新增变化，以及官方模型准入和返利路径。
不是全仓逐函数审计，也没有运行候选业务测试或连接生产核验。

## 每次同步如何更新

1. 用户提供来源网址/分支后固定完整提交，核对来源和本项目是否发生变化。
2. 优先保留用户个人要求；汇总新版内容、实际冲突、适配方式和依赖，供用户确认。
3. 用户确认更新内容并说明如何处理后，按指定范围实施；无冲突采用最新版不等于自动实施授权。
4. 产品选择更新规则文档；实施状态更新本页；代码说明更新对应功能文档。
5. 合并完成后更新当前基线及状态，同时追加合并历史；发布时追加本项目版本记录。
   保留过去的来源与结果映射，不另建按日期分裂的计划/完成总结。
