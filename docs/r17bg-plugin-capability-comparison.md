# BPS 与 Cookie Pin 的替换边界

核对日期：2026-10-06。依据：本地 BPS 仓库 README、当前宿主与 Cookie Pin 源码、
目标生产数据库的只读查询。不是两者功能等价或生产切换许可。

## 已核实状态

- 目标服务器当前仍运行回退镜像 `sub2api:r3-v028-3a4f527`。
- 当前连接的 `sub2api` 数据库中，`sub2api_plugin_installations`、
  `sub2api_plugin_bindings` 的计数均为 0。
- 历史对话记载 BPS 0.7.1 已安装，但本地 BPS README 标记运行时 0.6.5，
  并存在另一轮 Prism 迁移工作。本轮未修改该仓库。
- 以上信息不一致，不能用本地版本或历史口述替代生产包身份核对；当前查询仅
  能说明该数据库没有登记记录，不能排除另一部署、旧目录或其他数据库仍有旧包。

## 能力表

| 维度 | 本地 BPS 运行时 | Cookie Pin 0.3.10 | 替换影响 |
| --- | --- | --- | --- |
| 出站目的地 | 合格请求改走 basispoints，其他走 Codex | 保留捕获的 Codex 请求路径 | 不提供 basispoints 路由 |
| 账号范围 | 插件内账号白名单、套餐限制，另受宿主灰度约束 | 宿主稳定账号散列灰度；暂停名单不是测试白名单 | 灰度比例不能隔离指定实验账号 |
| 模型和 effort | 模型白名单，最高 xhigh，max 降为 xhigh | 探针模型/effort 可配置，业务请求不实现 BPS 模型映射 | 不继承 BPS 模型处理 |
| 图片 | 内联图片上传附件并缓存；不支持者回落 Codex | 不实现 BPS 附件上传 | 图片工作流需要单独验收 |
| 工具 | native_tools / OfficeJS 桥接、SSE 还原、update_plan 双向转换 | 转发 HTTP/SSE，不实现这些转换 | 工具能力不等价 |
| 认证 | 使用宿主提供的 OAuth 令牌；不是重授权登录流程 | 同样使用宿主令牌，不刷新或登录账号 | 不能当作凭据修复 |
| 代理 | 宿主传入代理出口 | 指定代理不可用时拒绝直连回退 | 原有代理边界必须保留 |
| Cookie | 不是当前 README 所述核心能力 | 被动捕获、按账号注入、丢弃/重摇 | 可提供新的可选观察能力 |
| 失败处理 | basispoints 回落 Codex、usage-policy 冷却 | HTTP/传输有限重试；明确错答有限重摇和退避 | 冷却与回落语义不等价 |
| 主动流量 | 按业务工作流产生附件/回落请求 | 可选主动质量探针，默认关闭 | 必须独立测量并限定成本 |
| 日志 | 路由/工具计数及部分原文排查文件 | Cookie 只暴露元信息；探针状态与原因 | 不迁移原文排查逻辑 |
| WebSocket | 本轮没有完成全部入口验证 | 本轮 HTTP/SSE 验收不证明 WebSocket 被覆盖 | 不宣称全面兼容 |

宿主 `PluginManager.Enable` 对 `openai.oauth.outbound_transport.v1` 执行独占。
不同插件 ID 不是原地更新，不能自动迁移配置，也不能同时启用以叠加上述能力。

## 决策

本轮不自动卸载、停用或替换生产 BPS，也不新增插件链。
先完成独立候选包验收；生产切换前重新核对实际部署的包、配置、绑定及必需业务能力。
如果 basispoints、图片或工具桥接必须继续保留，Cookie Pin 不能作为直接替代品，
应保留旧路径并将 Cookie 方案留在隔离环境评估。

当前没有有效旧安装记录，故没有宣称完成生产 BPS → Cookie Pin → BPS 回滚演练。
候选包验收使用独立本地公钥信任策略，不修改生产公钥或插件配置。
